## 数据中心网络规划指南

### 1. 三层架构设计原则

采用核心-汇聚-接入三层模型。核心层负责高速转发，建议部署2台框式交换机（如Cisco N9500或华为CE12800），配置双主控、双电源。汇聚层作为策略边界，每机架/每列部署2台（如Cisco N9300或华为CE6865），接入层采用1U交换机（如Cisco N9200或华为CE5855），每台接入交换机连接20-30台服务器。

**端口规划示例**：
- 核心-汇聚：40GE/100GE，每汇聚交换机上行2条40GE
- 汇聚-接入：10GE/25GE，每接入交换机上行2条10GE
- 接入-服务器：1GE/10GE，服务器双网卡分别接不同接入交换机

### 2. VLAN划分与配置

按业务类型划分VLAN，建议范围：
- VLAN 10-99：管理网（带外管理）
- VLAN 100-199：存储网（iSCSI/NFS）
- VLAN 200-299：业务网（Web/App）
- VLAN 300-399：数据库网
- VLAN 400-499：DMZ区

**配置示例（Cisco）**：
```
vlan 200
 name PROD-WEB
interface Vlan200
 ip address 10.200.1.1 255.255.255.0
 standby 1 ip 10.200.1.254
 standby 1 priority 110
 standby 1 preempt
```

**Trunk端口配置**：
```
interface GigabitEthernet1/0/1
 switchport trunk encapsulation dot1q
 switchport mode trunk
 switchport trunk allowed vlan 200-299
```

### 3. 端口聚合配置

服务器双网卡聚合采用LACP模式，交换机侧配置：
```
interface range TenGigabitEthernet1/0/1-2
 channel-group 10 mode active
 channel-protocol lacp
!
interface Port-channel10
 switchport mode trunk
 switchport trunk allowed vlan 200
 spanning-tree portfast trunk
```

**阈值建议**：聚合链路负载均衡采用src-dst-ip哈希，单条链路利用率不超过70%。若超过，需增加聚合成员或升级端口速率。

### 4. 高可用设计

#### 4.1 堆叠（Stack）
接入层交换机采用堆叠，将2-4台物理设备虚拟为1台逻辑设备。华为iStack配置：
```
stack slot 0 priority 200
stack slot 1 priority 100
interface stack-port 0/1
 port interface XGE1/0/1 enable
```
堆叠后使用MAD检测（直连+Relay），防止双主。

#### 4.2 VRRP/HSRP
汇聚层作为网关，运行VRRP。主设备优先级120，备设备100，抢占延迟10秒。配置BFD联动，故障检测时间200ms。

```
interface Vlan200
 vrrp 1 ip 10.200.1.254
 vrrp 1 priority 120
 vrrp 1 preempt delay minimum 10
 vrrp 1 track 1 interface TenGigabitEthernet1/0/1 30
```

### 5. 带宽规划与冗余策略

**带宽计算**：接入层每服务器平均2Gbps，收敛比3:1，则每接入交换机上行需6Gbps，采用2条10GE聚合。汇聚层每台接入交换机下行10Gbps，按20台接入计算，汇聚上行需200Gbps，采用4条100GE。

**冗余策略**：
- 设备级：核心/汇聚双机，接入堆叠
- 链路级：所有上行链路双归，跨设备聚合（M-LAG/VPC）
- 电源级：双路PDU，分别接A/B路
- 故障切换目标：核心故障<1秒，汇聚故障<3秒，接入故障<5秒

**M-LAG配置示例（华为）**：
```
interface Eth-Trunk1
 mode lacp-static
 dfs-group 1
 peer-link 1
```
需确保peer-link带宽≥业务链路总带宽的50%。

### 6. 验收检查清单

1. 所有VLAN网关VRRP状态正常，主备切换测试通过
2. 聚合链路LACP状态为“up”，流量负载均衡
3. 堆叠系统MAD检测生效，拔纤测试无双主
4. 带宽利用率峰值<70%，丢包率<0.01%
5. 冗余切换时间满足SLA（核心<1s，汇聚<3s）
6. 生成树根桥与VRRP主设备一致，避免次优路径
