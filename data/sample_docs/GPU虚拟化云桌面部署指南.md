# GPU 虚拟化云桌面部署指南

## 一、方案概述

GPU 虚拟化云桌面适用于 3D 设计、视频渲染、GIS 等高性能图形场景。通过 NVIDIA 显卡虚拟化技术，将一块物理 GPU 资源切分成多个虚拟 GPU，分配给不同的云桌面用户。

## 二、硬件要求

### 服务器配置
- CPU：至少 2 颗，每颗 16 核以上
- 内存：每 GPU 卡配置 128GB 以上
- GPU：NVIDIA A10 / A16 / L20 等 vGPU 支持卡
- 存储：SSD 缓存 + HDD 数据盘

### 网络要求
- 管理网络：千兆以上
- 存储网络：万兆以上
- 业务网络：万兆以上

## 三、部署步骤

### 1. NVIDIA 授权服务器部署
1. 安装 NVIDIA License Server
2. 导入授权文件
3. 配置 License 服务端口（默认 7070）
4. 验证 License Server 正常运行

### 2. GPU 资源池配置
1. 在虚拟化平台添加 GPU 主机
2. 配置 vGPU 类型（如 A16-1Q / A16-2Q / A16-4Q）
3. 设置 GPU 资源调度策略
4. 配置 GPU 过载保护

### 3. 虚拟机模板制作
1. 创建基础虚拟机
2. 安装 vGPU 驱动（注意版本匹配）
3. 安装设计软件（CAD / CATIA 等）
4. 优化系统性能
5. 制作模板

## 四、性能调优

### 显卡加速配置
- 开启硬件加速
- 调整显存分配
- 优化帧缓冲设置

### 软件授权模式
- 网络浮动授权
- 本地单机授权
- 混合授权模式

### 常见问题
- 授权冲突：检查授权服务器连接
- 画面卡顿：检查显存是否足够
- 驱动不兼容：确认 vGPU 驱动版本

## 五、适用场景

| 场景 | 推荐 vGPU 类型 | 显存建议 |
|------|---------------|---------|
| 2D 办公 | 1Q | 1GB |
| 轻量 3D | 2Q | 2GB |
| 中型设计 | 4Q | 4GB |
| 重型渲染 | 8Q / 16Q | 8GB+ |
