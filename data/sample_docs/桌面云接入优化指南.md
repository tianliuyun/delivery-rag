# 桌面云接入速度优化指南

## 一、常见问题现象

用户反馈桌面云登录慢、打开应用卡、操作延迟高。可能的原因包括网络问题、服务器资源不足、客户端配置不当等。

## 二、网络排查步骤

1. 检查客户端到服务器的网络延迟（ping 测试）
2. 确认带宽是否充足（建议每用户至少 2Mbps）
3. 检查是否有丢包（丢包率应低于 1%）
4. 内外网接入路径优化

## 三、客户端优化

1. 升级客户端到最新版本
2. 开启客户端硬件加速
3. 设置开机自启动 + 系统托盘常驻
4. 清理客户端缓存

## 四、服务器端优化

1. 检查 CPU / 内存 / 磁盘 IO 使用率
2. 确认 GPU 资源配置（3D 场景）
3. 优化虚拟机模板配置
4. 调整并发连接数限制

## 五、性能指标参考

| 指标 | 良好 | 可接受 | 需优化 |
|------|------|--------|--------|
| 登录时间 | <5s | 5-10s | >10s |
| 操作延迟 | <100ms | 100-200ms | >200ms |
| 帧率（3D） | >30fps | 20-30fps | <20fps |

## 六、典型案例

某券商 18000 点桌面云项目，客户端接入速度从比竞品慢 2s 优化到反超快 8s+，累计优化 10s+。主要优化手段：双入口架构（内网直连+外网负载均衡代理）+ 启动策略优化 + 客户端整体现代化重构。
