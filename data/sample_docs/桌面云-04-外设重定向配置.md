## 桌面云外设重定向配置与排障指南

### 1. 适用范围与背景

本文适用于基于华为FusionAccess、Citrix Virtual Apps and Desktops等主流桌面云平台的交付与运维场景。重点解决USB设备、打印机、智能卡读卡器在虚拟桌面中无法重定向的问题。典型根因包括：外设策略未放行、客户端版本过旧、驱动不兼容。

### 2. 外设重定向基础配置

#### 2.1 USB设备重定向

**配置步骤（以华为FusionAccess为例）：**

1. 登录管理平台，进入“策略管理 > 外设策略”。
2. 新建或编辑策略，启用“USB重定向”开关。
3. 在“USB设备过滤”中，按VID/PID放行目标设备。例如：
   - 读卡器：`VID_058F&PID_9540`
   - UKey：`VID_096E&PID_0201`
4. 设置“重定向模式”为“独占”或“共享”，推荐读卡器使用“独占”。
5. 将策略绑定至虚拟机池或用户组。
6. 在客户端侧确认“USB重定向”选项已勾选。

**验证方法：**

- 在虚拟机内执行 `Get-PnpDevice -Class USB`（PowerShell），查看设备是否出现。
- 使用 `usbview.exe` 检查设备树中是否包含重定向设备。
- 若设备显示黄色感叹号，进入第4节排查驱动。

#### 2.2 打印机重定向

**配置步骤：**

1. 策略中启用“打印机重定向”，选择“仅重定向默认打印机”或“重定向所有打印机”。
2. 若使用网络打印机，确保虚拟机可访问打印服务器TCP 445、9100端口。
3. 客户端本地安装打印机驱动，版本需与虚拟机内驱动一致。
4. 启用“通用打印驱动回退”选项，避免驱动缺失。

**验证方法：**

- 在虚拟机内打开“设备和打印机”，确认出现“重定向的打印机”。
- 执行 `Get-Printer | Format-List Name,DriverName,PortName` 检查端口是否为 `TS001` 或 `ClientPrinter`。
- 打印测试页，若失败，检查客户端到虚拟机的TCP 3389（RDP）或1494（ICA）端口是否放行。

#### 2.3 读卡器重定向

**配置步骤：**

1. 策略中启用“智能卡重定向”和“USB重定向”。
2. 对于非智能卡类读卡器（如身份证读卡器），必须使用USB重定向并放行VID/PID。
3. 在虚拟机内安装读卡器厂商驱动，建议使用WHQL签名版本。
4. 若使用PC/SC接口，确保虚拟机内“Smart Card”服务已启动，启动类型为“自动”。

**验证方法：**

- 执行 `certutil -scinfo` 检查智能卡服务状态。
- 使用厂商测试工具（如身份证读卡器测试程序）读取卡片。
- 若设备管理器中出现“Microsoft Usbccid Smartcard Reader”，但读卡失败，检查驱动版本是否匹配。

### 3. 常见故障根因与排障流程

#### 3.1 外设策略未放行

**现象：** 设备在客户端可见，但虚拟机内无设备。

**排查：**

1. 检查策略是否绑定到当前用户/虚拟机。
2. 检查USB过滤规则是否包含设备VID/PID。获取方法：客户端执行 `Get-PnpDevice | Where-Object {$_.Class -eq 'USB'} | Select-Object InstanceId`。
3. 检查策略优先级：用户策略 > 池策略 > 全局策略。
4. 重启客户端服务 `HuaweiDesktopService` 或 `Citrix Desktop Service`。

#### 3.2 客户端版本过旧

**现象：** 部分USB 3.0设备或新型读卡器无法识别。

**排查：**

1. 对比客户端版本与虚拟机Agent版本，要求主版本一致。
2. 检查客户端日志：`%ProgramData%\Huawei\DesktopClient\logs\client.log`，搜索“USB”或“redirect”。
3. 升级客户端至最新稳定版，例如FusionAccess Client V200R006C10SPC200及以上。
4. 确认客户端操作系统补丁：Windows 10需KB5000000以上，Windows 7需KB4474419。

#### 3.3 驱动不兼容

**现象：** 设备在虚拟机内出现但报错“代码 10”或“代码 28”。

**排查：**

1. 在虚拟机内打开设备管理器，查看设备属性 > 详细信息 > 硬件ID。
2. 对比客户端与虚拟机内驱动版本，要求一致。
3. 若使用通用驱动，尝试替换为厂商专用驱动。
4. 对于USB 3.0设备，确保虚拟机内安装USB 3.0控制器驱动（如Intel USB 3.0 eXtensible Host Controller）。
5. 禁用驱动签名强制（临时测试）：`bcdedit /set testsigning on`，重启后测试，生产环境不建议。

### 4. 端口与命令速查

| 用途 | 端口/命令 |
|------|-----------|
| RDP重定向 | TCP 3389 |
| ICA重定向 | TCP 1494, 2598 |
| 打印机RAW打印 | TCP 9100 |
| 打印共享 | TCP 445 |
| 查看USB设备 | `Get-PnpDevice -Class USB` |
| 查看打印机 | `Get-Printer` |
| 智能卡服务 | `sc query SCardSvr` |
| 客户端日志 | `%ProgramData%\Huawei\DesktopClient\logs\` |

### 5. 交付验证清单

1. 策略已绑定且优先级正确。
2. 客户端与Agent版本一致。
3. 设备VID/PID已放行。
4. 虚拟机内驱动已安装且无报错。
5. 端口放行且无防火墙拦截。
6. 实测设备读写正常，打印测试页成功，读卡器可读取卡片。
