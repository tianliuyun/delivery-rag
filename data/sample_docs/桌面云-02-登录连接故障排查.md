## 桌面云登录与连接故障排查手册

## 1. 适用范围

本手册适用于企业桌面云（基于 HDP/Blast/PCoIP 等协议）交付后运维阶段，针对以下三类高频故障提供标准化排查路径：

- 登录超时：客户端发起登录后 30 秒内未进入桌面
- 连接断开：会话建立后 5 分钟内非主动断连
- 认证失败：AD/LDAP/双因子认证返回错误

## 2. 通用信息收集

排查前先执行以下命令，记录基线数据：

```bash
# 客户端到接入网关的延迟与丢包
ping -c 20 <gateway_ip>
# 结果阈值：平均延迟 < 30ms，丢包率 < 1%

# 路由追踪
tracert -d <gateway_ip>   # Windows
traceroute -n <gateway_ip> # Linux

# 端口连通性
telnet <gateway_ip> 443
telnet <gateway_ip> 8443
```

## 3. 登录超时排查

### 3.1 网络延迟检查

1. 在客户端执行 `ping -c 50 <gateway_ip>`，若平均延迟 > 50ms 或抖动 > 20ms，判定为网络质量问题。
2. 检查 MTU：`ping -f -l 1472 <gateway_ip>`，若提示分片，将 MTU 从 1500 降至 1400。
3. 检查 DNS 解析：`nslookup <gateway_fqdn>`，解析时间应 < 100ms。

### 3.2 会话网关状态

1. 登录网关管理后台，检查服务状态：
   ```bash
   systemctl status hdp-gateway
   netstat -tunlp | grep -E '443|8443|9443'
   ```
2. 查看并发会话数：`gateway-cli session count`，若超过许可证 90%，触发排队超时。
3. 检查网关日志：
   ```bash
   tail -f /var/log/hdp/gateway.log | grep -i timeout
   ```

### 3.3 阈值建议

| 指标 | 正常 | 警告 | 故障 |
|------|------|------|------|
| 网关 CPU | <60% | 60–80% | >80% |
| 会话建立耗时 | <5s | 5–15s | >15s |
| 登录总耗时 | <15s | 15–30s | >30s |

## 4. 连接断开排查

### 4.1 会话网关状态

1. 确认网关与桌面代理（Agent）心跳：
   ```bash
   agent-cli status
   # 心跳间隔应 ≤ 5s，连续 3 次丢失判定断连
   ```
2. 检查会话保持策略：空闲超时默认 15 分钟，最大会话 8 小时。
3. 抓包确认断连方向：
   ```bash
   tcpdump -i eth0 host <client_ip> and port 8443 -w drop.pcap
   ```

### 4.2 证书有效期

1. 检查网关证书：
   ```bash
   openssl x509 -in /etc/hdp/gateway.crt -noout -dates
   ```
2. 阈值：剩余有效期 < 30 天必须更换；< 7 天将导致 TLS 握手随机失败。
3. 检查 CRL/OCSP 可达性，超时 > 3s 会引发断连。

### 4.3 许可证余量

1. 查询许可证：
   ```bash
   license-cli query
   # 关注：Total / Used / Available
   ```
2. 若 Available = 0，新连接被拒绝，已连接会话可能被强制回收。
3. 阈值：余量 < 10% 时告警，< 5% 时停止新会话接入。

## 5. 认证失败排查

### 5.1 认证链路检查

1. 确认 AD/LDAP 连通性：
   ```bash
   ldapsearch -x -H ldap://<dc_ip>:389 -D "cn=admin,dc=corp,dc=com" -w <pwd> -b "dc=corp,dc=com" "(sAMAccountName=testuser)"
   ```
2. 检查时间同步，Kerberos 允许偏差默认 5 分钟：
   ```bash
   w32tm /stripchart /computer:<dc_ip>   # Windows
   ntpq -p                                # Linux
   ```
3. 双因子认证（RADIUS）测试：
   ```bash
   radtest testuser <pwd> <radius_ip> 0 <shared_secret>
   ```

### 5.2 证书有效期

1. 检查认证服务器证书：
   ```bash
   openssl s_client -connect <dc_ip>:636 -showcerts </dev/null 2>/dev/null | openssl x509 -noout -dates
   ```
2. 若证书过期，LDAPS 认证全部失败，需立即续签并重启认证服务。

### 5.3 许可证余量

1. 认证类许可证（如并发用户数）不足时，返回 `LICENSE_EXCEEDED`。
2. 执行 `license-cli query --feature auth`，确认认证模块余量。
3. 阈值：认证许可证余量 < 5 个时，提前扩容。

## 6. 排查顺序建议

1. 先查网络延迟与端口连通性（3.1）
2. 再查网关与认证服务状态（3.2 / 5.1）
3. 检查证书有效期（4.2 / 5.2）
4. 最后确认许可证余量（4.3 / 5.3）

按此顺序可在 10 分钟内定位 80% 的登录与连接类故障。
