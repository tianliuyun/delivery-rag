# 分布式存储 EDS 常见故障排查

## 一、磁盘故障

### 现象
- 存储池告警磁盘异常
- 节点下线或降级
- IO 延迟升高

### 排查步骤
1. 查看磁盘 SMART 信息
2. 检查磁盘是否物理损坏
3. 确认是否是误报（拔出重插测试）
4. 查看重建进度

### 处理方法
- 单块磁盘故障：等待自动重建
- 多块磁盘故障：联系技术支持
- 定期检查磁盘健康状态

## 二、网络故障

### 现象
- 存储节点失联
- IO 卡住或超时
- 集群裂脑

### 排查步骤
1. 检查存储网络连通性
2. 确认万兆网卡状态
3. 查看交换机端口错误计数
4. 检查网络风暴

## 三、性能问题

### 常见原因
1. 磁盘性能瓶颈（SSD vs HDD）
2. 网络带宽不足
3. 缓存命中率低
4. 小文件过多

### 优化建议
1. 增加 SSD 缓存层
2. 开启智能分层
3. 优化条带大小
4. 小文件合并

## 四、日常运维建议

- 每天检查集群健康状态
- 每周检查磁盘 SMART
- 每月做一次性能基线对比
- 重要数据开启多副本（至少 3 副本）
