## 服务器硬件故障排查手册

### 1. 适用范围与前置准备

本手册适用于主流x86机架式服务器（Dell PowerEdge、HPE ProLiant、浪潮NF系列等）的现场硬件故障判断与更换。执行任何硬件操作前，必须完成以下准备：

1. 登录带外管理口（iDRAC/IPMI/iLO），确认告警日志。默认地址通常为 `https://<BMC_IP>`，默认账号密码见资产表。
2. 通过SSH登录BMC，执行 `ipmitool sel list` 查看系统事件日志（SEL）。
3. 准备防静电手环、十字螺丝刀、备件标签、维修工单。
4. 若业务在线，先执行 `virsh list --all` 或 `kubectl get nodes` 确认业务影响范围，并申请维修窗口。

### 2. 电源报警判断与处理

#### 2.1 常见告警特征

- BMC SEL中出现 `Power Supply redundancy lost` 或 `PSU failure`。
- 前面板电源指示灯琥珀色闪烁（约1Hz），或BMC界面PSU状态为 `Failed`。
- `ipmitool sdr type "Power Supply"` 输出中 `Status` 为 `ns`（no state）或 `cr`（critical）。

#### 2.2 电源老化判断阈值

- 电源风扇转速持续低于 `2000 RPM`（正常约 `4000-8000 RPM`）。
- 输入电压正常（220V±10%）时，输出电压12V偏差超过 `±5%`（即低于11.4V或高于12.6V）。
- 同一电源模块累计运行超过 `5年` 或 `40000小时`，且出现间歇性 `PSU failure` 告警，判定为老化。

#### 2.3 处理步骤

1. 确认另一路电源是否正常供电。若为冗余电源，可在线更换故障模块。
2. 记录故障PSU槽位（通常标为PSU1/PSU2）。
3. 拔下故障PSU电源线，按压释放卡扣，水平抽出模块。
4. 插入同型号备件，听到卡扣锁定声，接回电源线。
5. 观察指示灯转为绿色常亮，执行 `ipmitool sel clear` 清除历史告警。
6. 若更换后仍报警，检查电源背板或主板供电电路，转主板告警流程。

### 3. 风扇异响与损坏判断

#### 3.1 异响类型与对应故障

- **高频啸叫**：轴承磨损，转速波动超过 `±15%`。
- **周期性咔哒声**：扇叶变形或异物，需停机检查。
- **低频嗡嗡声**：风扇积灰导致动平衡失效，转速低于 `1500 RPM`。

#### 3.2 检查命令与阈值

```bash
ipmitool sdr type Fan
# 关注读数：若某风扇转速 < 1500 RPM 或 > 12000 RPM，判定异常
ipmitool sensor get "Fan1"
# 查看 Status 是否为 cr（critical）
```

#### 3.3 更换流程

1. 通过BMC确认故障风扇编号（如Fan3）。
2. 若支持热插拔，直接拔下风扇模块；否则需关机并断开电源。
3. 更换同规格风扇（注意风压与转速参数一致）。
4. 开机后执行 `ipmitool sdr type Fan` 确认转速恢复至 `3000-8000 RPM`。
5. 若更换后BMC仍报 `Fan failure`，检查风扇背板连接器或主板FAN接口。

### 4. 指示灯异常与主板告警

#### 4.1 指示灯编码

- **电源灯绿色常亮**：正常。
- **电源灯琥珀色常亮**：系统降级（如冗余丢失）。
- **电源灯琥珀色闪烁**：严重故障，需查SEL。
- **UID灯蓝色**：人工标记，非故障。
- **健康灯红色**：主板告警，通常伴随 `CPU IERR` 或 `Memory CRC error`。

#### 4.2 主板告警判断

执行 `ipmitool sel list`，若出现以下条目，判定为主板或CPU相关故障：

- `CPU1 IERR`
- `Uncorrectable memory error`
- `PCIe fatal error`
- `Motherboard voltage out of range`

检查 `ipmitool sdr type Voltage`，若 `Vcore` 或 `Vcc` 偏差超过 `±5%`，为主板供电模块故障。

#### 4.3 处理建议

1. 主板告警优先尝试重置BIOS（跳线或BMC命令 `ipmitool mc reset cold`）。
2. 若告警持续，记录SEL日志并申请更换主板。
3. 更换主板需重新配置BIOS、BMC IP、RAID卡信息，建议提前导出配置。

### 5. 硬件更换流程与维修窗口建议

#### 5.1 标准更换流程

1. 提交变更单，注明故障部件、影响业务、回滚方案。
2. 通知业务方，确认可接受停机时间。
3. 执行数据备份或虚拟机迁移（`virsh migrate` 或 `vMotion`）。
4. 关机：`shutdown -h now` 或通过BMC `power off`。
5. 断开电源线与网线，佩戴防静电手环。
6. 更换硬件，记录序列号与备件标签。
7. 开机，进入BMC确认无告警，执行 `ipmitool sel list` 验证。
8. 恢复业务，观察30分钟，关闭变更单。

#### 5.2 维修窗口建议

- **电源/风扇热插拔**：可安排在业务低峰期（如凌晨2:00-4:00），无需停机。
- **主板/CPU/内存更换**：需停机，建议窗口 `2-4小时`，预留BIOS配置与业务验证时间。
- **批量固件升级**：单独窗口，建议 `4小时`，避免与硬件更换混用。
- **紧急故障**：若业务已中断，立即执行，但需同步通知业务方与值班经理。

#### 5.3 更换后验证清单

- BMC `Overall Status` 为绿色。
- `ipmitool sel list` 无新增critical条目。
- 操作系统 `dmesg | grep -i error` 无硬件报错。
- 业务进程/容器/Pod全部Running。
- 记录更换时间、备件SN、操作人，归档至CMDB。
